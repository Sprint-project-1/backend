# 팀원 역할 및 R&R

> 팀원 명단을 임의 배정하지 않는다. 현재 GitHub 저장소 담당자와 DB/API 담당자는 기존 팀 대화에서 맡은 영역이 있더라도, 여기에는 본인이 확인한 이름/책임을 팀이 입력한다. `main`에는 FE scaffold가 있으나 코드 존재만으로 담당자를 추정하지 않는다.
