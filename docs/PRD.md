# PRD — 기능별 요구사항

> CineFund 내부 API/DB 식별자는 초안 기준 `movieId`, `tmdbId`, `fundingId`, `nickname`, `amount`, `comment`, `createdAt`이다. TMDB는 초기 영화 데이터 적재에만 쓰며 사용자 요청은 DB 데이터를 사용한다. Figma에 가입 화면은 없고 익명 모의 펀딩 입력 UI가 있다. 미확정 API 세부는 제안/TBD다.

> 구현 현황: 이전 확인한 GitHub `main`에는 Vite/React JSX 라우팅과 화면 placeholder가 있다. **이 ZIP의 BE**에는 영화 100편 메타데이터(JSON·Prisma Movie), 마이그레이션/시드, Express `/health`가 준비됐다. 아래 사용자 기능/API는 **요구사항이지 완료된 서비스 API가 아니다.** BE 코드의 `main` 병합 여부는 별도 확인하고 화면 경로 차이는 [PAGE_SPEC](PAGE_SPEC.md) 참조.

## 상세 동작 및 검증

- 닉네임 최대 8글자, 코멘트 최대 100글자는 모의 펀딩 입력에 적용할 초기 기획 제한이다. 서버 검증/문자 수 기준은 TBD이며 제안은 trim 후 Unicode code point 기준이다.
- `amount`는 양의 정수(최소/최대값 TBD) 제안이다. **영화 선정은 제작비 최소 25,000 USD(선정용 고정 환율 1,400 KRW로 3,500만 원 상당)** 기준이며, 원본 제작비는 USD로 저장한다. 후원액과 누적액은 KRW다. 현재 목표액 컬럼이 없어 달성률은 계산하지 않는다.
- 기본 목록 랜덤이 확정되어 있으나 페이지 간 랜덤 고정 방식은 TBD. 제안: 요청 간 동일한 결과 순서를 유지한다.
- 비교 결과 항목 후보: 제목, 개봉일, 장르, 슬로건, 제작비(USD), 누적 펀딩(KRW). 팀 확정 전 구현 계약으로 간주하지 않는다.
- 목록/상세 JSON 및 오류 형식은 [API 명세](API_SPEC.md)를 따른다.

## Figma 시안에서 확인한 UI 및 추가 제안/TBD

- 공통 헤더와 비교 선택 화면에 영화 검색 UI가 보인다. 화면 요소는 반영하되 검색 기능/API의 MVP 범위는 팀 결정 전까지 TBD다.
- 비교 결과 시안에는 설명, 감독, 펀딩 금액 및 진행 표시가 보인다. **`overview`, `director`, `posterPath`, `originalTitle`, `koreanCertification`은 이미 JSON과 Prisma Movie 필드로 준비**되어 있지만 달성률은 기준 미정으로 구현 대상에서 보류하며 비교 API의 응답 항목은 미확정이다.
- 비교 결과에 `AI 비교 요약` 버튼/팝업 시안이 있다. AI 요약은 기존 요구사항에 없으므로 MVP 포함 여부, 외부 API, 비용, 데이터 전달 정책 합의 전까지 구현 범위가 아니다.
- Figma 상세 시안의 감독·설명(시놉시스)은 TMDB JSON 수집 및 DB 저장 대상이다. **실제 서비스 상세 API 응답과 FE 연동은 아직 미구현/미합의**다.
- 상세 시안은 코멘트 페이지 번호를 사용하지만 API 초안은 cursor를 사용한다. 서버 페이지 방식 또는 FE의 페이지-커서 매핑 중 하나를 API 담당자와 합의해야 한다.
- 홈 시안에는 랭킹 Top 3 레일이 보이고 `/ranking` 시안은 목록형이다. 누적액 집계 API와 원화 표시 정책을 확정해 데이터 표시를 맞춘다.
- 펀딩 폼/코멘트 수정 팝업은 UI 요구다. 이는 계정 등록이 아니며, 익명 기록 생성·수정 backend 계약은 API 담당자와 합의한다.
- 결과 시안의 AI 요약 팝업은 기존 기획 밖이다. 포함 여부와 외부 API/비용/데이터 정책은 TBD.
- Figma에는 데스크톱·태블릿·모바일 화면이 있다. 화면별 동작/브레이크포인트와 접근성 상태를 보완한다.
