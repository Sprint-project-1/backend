# PRD — 기능별 요구사항

> CineFund 내부 API/DB 식별자는 초안 기준 `movieId`, `tmdbId`, `fundingId`, `nickname`, `amount`, `comment`, `createdAt`이다. TMDB는 초기 영화 데이터 적재에만 쓰며 사용자 요청은 DB 데이터를 사용한다. Figma에 가입 화면은 없고 익명 모의 펀딩 입력 UI가 있다. 미확정 API 세부는 제안/TBD다.

> 구현 현황: GitHub `main`에는 Vite/React JSX 앱이 있다. 영화 탐색·비교 결과·랭킹은 예시 데이터 기반 UI가 구현되어 있고 상세·비교 선택은 placeholder다. 백엔드 API 연동은 미완료다. 페이지별 현재 동작은 [PAGE_SPEC](PAGE_SPEC.md)에서 관리한다.

## 상세 동작 및 검증

- 닉네임 최대 8글자, 코멘트 최대 100글자, 영문자와 숫자를 포함하는 펀딩 비밀번호 8~12글자는 입력 제한이다. 코멘트 빈 값 허용과 공백 정규화는 TBD다. 비밀번호 규칙은 생성·취소·수정 요청에 동일하게 적용한다.
- `amount`는 양의 정수이며 통화는 KRW다. 최대 금액은 PostgreSQL signed `BIGINT` 범위로 제한하는 API 제안이다.
- 기본 목록 랜덤이 확정되어 있으나 페이지 간 랜덤 고정 방식은 TBD. 제안: 요청 간 동일한 결과 순서를 유지한다.
- 비교 결과 항목은 후보: 제목, 개봉일, 장르, 슬로건, 제작비/목표액, 누적 펀딩, 달성률. 팀 확정 전 구현 계약으로 간주하지 않는다.
- 목록/상세 JSON 및 오류 형식은 [API 명세](API_SPEC.md)를 따른다.

## Figma 시안에서 확인한 UI 및 추가 제안/TBD

- 공통 헤더와 비교 선택 화면에 영화 검색 UI가 보인다. 검색은 API 명세의 제목 `q` 파라미터를 사용하는 제안이며 연도·장르·원제 검색은 포함하지 않는다.
- 비교 결과 시안에는 설명, 감독, 펀딩 금액, 달성률 비교 행이 보인다. 조회 필드는 API의 공통 영화 모델을 사용하며, NULL/0 제작비의 달성률은 계산 불가로 표시한다.
- 비교 결과에 `AI 비교 요약` 버튼/팝업 시안이 있다. AI 요약은 기존 요구사항에 없으므로 MVP 포함 여부, 외부 API, 비용, 데이터 전달 정책 합의 전까지 구현 범위가 아니다.
- 상세 시안의 감독·설명(시놉시스)은 seed 데이터에 포함된 필드이며 API 공통 영화 모델에서 반환한다.
- 영화 탐색 UI는 번호형 페이지 버튼, API 계약은 cursor 방식이다. FE는 방문 페이지별 cursor를 메모리에 보관하고 검색/정렬 변경 시 초기화한다. 코멘트 페이지 컨트롤도 API cursor에 맞춰 연결한다.
- 홈 시안에는 랭킹 Top 3 레일이 보이고 `/ranking` 시안은 목록형이다. API 명세의 공통 누적액·정렬·목표액 숫자 규칙을 사용한다.
- 펀딩 폼/코멘트 수정/취소 팝업은 UI 요구다. 이는 계정 등록이 아니며, 익명 기록 생성·수정·취소 계약은 [API 명세](API_SPEC.md)를 따른다. 동의 체크 문구/기록은 별도 결정이 필요하다.
- 결과 시안의 AI 요약 팝업은 기존 기획 밖이다. 포함 여부와 외부 API/비용/데이터 정책은 TBD.
- Figma에는 데스크톱·태블릿·모바일 화면이 있다. 화면별 동작/브레이크포인트와 접근성 상태를 보완한다.
